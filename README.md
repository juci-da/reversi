# Reversi App

Flaskを使用して開発したWebブラウザ向けのリバーシ（オセロ）アプリです。

## 概要

ブラウザ上でリバーシをプレイできるWebアプリケーションです。

リバーシの基本ルールを実装しており、石の配置、反転処理、手番管理、パス機能、勝敗判定を行うことができます。

また、トークンを利用した不正操作防止機能も実装しています。

## 使用技術

- Python
- Flask
- HTML
- JavaScript
- Bulma

## 実装機能

### ゲーム機能

- リバーシ盤面表示
- 石の配置
- 石の反転処理
- 配置可能マスの判定
- 手番管理
- パス機能
- ゲームリセット
- 石数カウント
- 勝敗判定

### 対戦機能

- 2人対戦
- 自動画面更新
- 手番表示
- 石数表示

### セキュリティ対策

- プレイヤーごとのトークン発行
- トークン認証
- 不正アクセス防止
